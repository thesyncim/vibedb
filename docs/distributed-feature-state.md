## How to update this page

1. Change `internal/featurestate/manifest.go` and cite production code or an executable test.
2. Run `go generate ./internal/featurestate`.
3. Run `go test ./internal/featurestate`. The test rejects stale output, invalid state transitions, duplicate rows, and missing evidence files.

The embedded capability matrix remains in [capabilities.md](capabilities.md). Operational instructions for the current static-shard commands remain in [operations/distributed.md](operations/distributed.md).
